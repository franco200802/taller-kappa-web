# el panel interno: no tiene contenido público.

# Este archivo NO es todo el robots.txt publicado: Cloudflare antepone su
# bloque gestionado ("Cloudflare Managed content"), que bloquea a los
# rastreadores de ENTRENAMIENTO de IA (GPTBot, ClaudeBot, Google-Extended…) y
# agrega la línea Content-Signal. Es una decisión del dueño, no un error
# (docs/seo/cloudflare-paso-a-paso.md, paso 6). Lighthouse marca Content-Signal
# como directiva desconocida (SEO 92 en vez de 100); Google la ignora.
#
# Ojo: un bot que tiene su propio grupo (User-agent: Googlebot) ignora el
# grupo "*". Por eso no hay grupos por bot: con uno para Googlebot, el
# Disallow de /admin dejaba de aplicarse a Google. Si algún día se quiere
# tratar distinto a un agente concreto, hay que repetir ahí el Disallow.
#
# /llms.txt (generado en cada build) resume la empresa y enlaza las páginas
# principales; es una ayuda opcional, no una directiva de rastreo.
